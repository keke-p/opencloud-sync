# OpenCloud Media Sync

公式 OpenCloud Android アプリと併用する、画像・動画のアップロード専用クライアント。
公式アプリのカメラアップロードが対象外としている、スクリーンショットや画面録画などの
任意のフォルダ (サブフォルダ含む) をパーソナルスペースへ自動アップロードする。

## 機能

- 複数フォルダを登録でき、各フォルダのサブフォルダまで含めて同期する
  - 端末側のフォルダは Android 標準のフォルダ選択画面で、アップロード先はアプリ内のリモートフォルダ選択で選ぶ
  - フォルダごとに動画もアップロードするか (オフなら画像のみ) を選べる
  - リモート側はローカルのサブフォルダ構成をそのまま再現する
  - 登録より後に追加されたファイルを自動同期する。既存ファイルはフォルダごとの「既存ファイルをアップロード」で送る
- 自動同期の条件: 「Wi-Fi 接続時のみ」(従量制でないネットワーク) / 「充電中のみ」
- 「今すぐ同期」: 条件を無視して即時実行する
- ローカルからリモートへの一方向。どちらで削除しても相手側には反映しない
- リモートに同名ファイルがある場合、同じサイズならアップロード済みとみなして省略し、違えば `name (2).ext` で保存する
- 10MB 以上のファイルはサーバーが対応していれば TUS で分割送信し、中断しても途中から再開する
- アップロード済みかどうかはローカル DB で判定する。アップロード後にファイルを編集しても再送しない

## 認証

公式アプリ (`eu.opencloud.android`) が AccountManager に登録したアカウントを使う。
本アプリはログイン処理を持たず、公式アプリでのログインを前提にしている。

1. アプリ内の「アカウントを選択」で公式アプリのアカウントを選ぶ
2. 「接続テスト」を押して、OS のアクセス許可ダイアログで許可する (初回のみ)

アクセストークンの更新は公式アプリの Authenticator が行う。
公式アプリで再ログインが必要になった場合は、通知とアプリ内に表示する。

サーバーURLは他アプリから読めないため、アカウント名 (`user@host[:port][/path]`) から
`https://` を仮定して推定する。http で運用している場合などは「URL編集」で直す。

## 新しいファイルの検知

- MediaStore の変更通知を WorkManager の content URI トリガーで受け、自動同期を予約する
- 検知漏れに備えて、設定した間隔 (15分〜6時間) で定期チェックする

## 再起動・省電力

- 端末の再起動後やアプリの更新後は、アプリを開かなくても同期が再開される
  - WorkManager が起動完了 (BOOT_COMPLETED) を受けて、ジョブを再登録する
  - 加えて `BootReceiver` が起動完了とアプリ更新 (MY_PACKAGE_REPLACED) を受け、登録を確認して自動同期を予約する
- 「バッテリーの最適化」が有効だと、自動同期が遅れたり止められたりする。アプリ内の「最適化の対象外にする」で除外を依頼できる
- 一部メーカー (Xiaomi / OPPO / Huawei / vivo など) の端末は独自の「自動起動」制限があり、許可しないと起動完了の通知が届かない。アプリ情報 (またはメーカーのセキュリティアプリ) から自動起動を許可する
- 設定の「強制停止」をすると、次にアプリを開くまで同期は止まる (Android の仕様)

## 必要な権限

| 権限 | 用途 |
|---|---|
| 写真と動画 (「すべて許可」) | 対象ファイルの検索と読み取り。Android 14 の「選択した写真のみ」では同期できない |
| メディアの位置情報 | 画像の位置情報 (EXIF) を削らずにアップロードする |
| 通知 | 進捗とエラーの表示 |

## ビルド

JDK 17 と Android SDK (API 35) が必要。

```sh
./gradlew assembleDebug      # app/build/outputs/apk/debug/opencloud-sync-debug.apk
./gradlew testDebugUnitTest
```

### リリースビルド (署名付き)

1. `keystore.properties.example` を `keystore.properties` にコピーし、鍵ファイルのパス・エイリアス・パスワードを書く
2. `./gradlew assembleRelease` → `app/build/outputs/apk/release/opencloud-sync-release.apk`

`keystore.properties` がない場合は未署名の `opencloud-sync-release-unsigned.apk` になる (そのままではインストールできない)。
鍵ファイル (`*.jks`) と `keystore.properties` は git 管理外。鍵をなくすと同じアプリとして更新できなくなるので別途バックアップする。

Play ストアでの公開は想定しておらず、APK を直接インストールする前提。
ユーザーが追加した CA 証明書 (自己署名サーバー向け) と平文 HTTP を許可している。

## 構成

| パッケージ | 内容 |
|---|---|
| `account` | 公式アプリのアカウント共有、トークン取得 |
| `remote` | WebDAV (PROPFIND / MKCOL / PUT)、TUS、Graph API (パーソナルスペースの取得) |
| `media` | MediaStore の検索 (RELATIVE_PATH の前方一致でサブフォルダを含める) |
| `data` | Room (同期フォルダ、アップロード記録) |
| `sync` | 同期処理本体、WorkManager のワーカーとスケジュール、通知 |
| `ui` | Jetpack Compose の画面 |
